# shevanio-pi repository identity

This repository owns the canonical `shevanio-pi` product and package coordinate:
`https://github.com/Shevanio/shevanio-pi`.

Repository-owned product wording must use `shevanio-pi`. Existing `gentle:*`,
`GENTLE_PI_*`, `.pi/gentle-ai`, installer, binary, contract, and schema names are
transitional compatibility identifiers and must not be renamed without a separate migration.
