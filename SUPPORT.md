# Support

`shevanio-pi` is not yet available from npm. Canonical install support will begin
only after a registry publication is verified.

Use the repository's issue forms for reproducible bugs and focused feature requests:
<https://github.com/Shevanio/shevanio-pi/issues/new/choose>.

Remove secrets and private data from examples. Report vulnerabilities through the
private process in [SECURITY.md](SECURITY.md), not through a public issue.
