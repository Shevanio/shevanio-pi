# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately through the
[GitHub security advisory form](https://github.com/Shevanio/shevanio-pi/security/advisories/new).
Do not open a public issue for an unpatched vulnerability or include credentials,
tokens, private repository content, or personal data in a report.

Include the affected revision, environment, reproduction steps, impact, and any
suggested mitigation. Maintainers will acknowledge the report and coordinate
disclosure after the risk is understood.

## Supported versions

`shevanio-pi` is not yet published on npm. Until a supported release policy is
announced, security fixes target the canonical repository's active development line.
